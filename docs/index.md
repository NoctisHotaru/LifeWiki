# Life Wiki

一份写给普通人的生活指南。这里不绕弯子，只把那些**第一次遇到、又不知道该问谁**的事，一步一步写清楚。

## 怎么用这个站

!!! tip "三个小提示"

    - **左侧导航**：按主题层层展开，点一下就能进对应文章。
    - **顶部搜索**：直接输入关键词，比如「值机」「验光」「助学金」，全文都能搜到。
    - **右上角按钮**：可以在浅色、深色之间切换；默认跟随你手机或电脑的日夜设置。

## 关于内容

!!! warning "请以官方信息为准"

    本站内容为经验整理，**票价、政策、办理流程都会变动**。涉及金额、证件、补贴、救助等关键事项时，请务必以官方渠道（车站公告、航空公司官网、学校资助中心、当地民政部门）的最新信息为准。

- 本站**纯静态**：没有账号、不需要注册、不能在线编辑，也不收集你的任何信息。
- 内容全部以 Markdown 编写，欢迎截图、复制、转发给需要的人。
